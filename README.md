# 💰 SpendWise – Expense Tracker

## 📌 About the Project
SpendWise is a modern and responsive Expense Tracker Web Application developed using HTML, CSS, and JavaScript. It helps users manage their daily expenses, track spending, and organize transactions easily.

## ✨ Features
- ➕ Add new expenses with name, amount, category, and date.
- ✏️ Edit existing expenses.
- 🗑️ Delete expenses with confirmation.
- 🔍 Filter transactions by category and date range.
- 💵 Calculate total expenses automatically.
- 📊 Display the largest expense and number of categories used.
- 💾 Save expense data in browser LocalStorage.
- 📱 Responsive design for desktop, tablet, and mobile.
- 🇮🇳 Display amounts in Indian Rupees (₹).
- 📅 Automatically set today's date in the expense form.

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Expense management and calculations
- LocalStorage – Store expense data in the browser

## 🚀 How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Add an expense by entering its name, amount, category, and date.
5. Manage your expenses using the Edit, Delete, and Filter options.

## 💾 Data Storage
The application uses the browser's LocalStorage to save expense records. Data remains available in the same browser unless its stored data is cleared. LocalStorage is specific to the browser and device; it does not automatically synchronize data across devices.
